# 产品设计文档

## 1. 产品名称
基于RFID温度感知与4G通信的冷链全链路溯源系统

## 2. 面向用户
- 疫苗/生物制品运输企业
- 生鲜水产品冷链物流
- 药品/医疗器械仓储管理
- 食品供应链监管机构

## 3. 解决问题
- **温控黑箱**：传统人工巡检无法7×24不间断监控，温度异常发现滞后
- **追溯低效**：纸质记录易丢失，无法进行历史趋势分析和责任追溯
- **断网丢数据**：运输途中网络不稳定，数据丢失导致溯源链断裂
- **责任不清**：交接环节缺少身份识别，出问题无法追责

## 4. 核心功能（MVP）

### 4.1 硬件终端
| 功能 | 说明 |
|------|------|
| 多标签RFID温度感知 | KF720读取3个温度标签，2秒周期，超2~8℃告警 |
| 4G-MQTT实时上报 | L610每2秒上报华为云IoTDA，含温度/位置/责任人 |
| GPS定位 | 每20秒更新经纬度，运输轨迹全程可追溯 |
| 断网缓存与补发 | W25Q Flash存储，联网自动补发，带event_time时间戳 |
| 责任人识别 | 5张RFID标签盘存识别，每6秒一次 |
| OLED显示 | 时间/4G状态/温度/GPS/责任人实时展示 |

### 4.2 前端平台
| 功能 | 说明 |
|------|------|
| 实时监控看板 | 温度卡片+合规仪表盘+GPS地图+温度曲线 |
| 报警处理 | 温度越限/断网补传告警，确认与清除 |
| 数据导出 | Excel报表导出（全量/单传感器） |
| 标签管理 | 传感器标签增删改查 |
| 管理后台 | 用户管理/任务分配/操作日志/推送日志 |

## 5. 关键设计决策
- **lianwang属性**：1=实时数据，0=断网补发，前端可区分展示
- **zeren属性**：RFID盘存识别责任人，实现"责任可究"
- **event_time**：UTC时间戳，确保补发数据时序正确
- **递归属性提取器**：前端自动适配任意数量传感器，无需硬编码

## 6. 性能指标
| 指标 | 参数 |
|------|------|
| 温度采集周期 | 2秒 |
| 数据上报周期 | 2秒 |
| GPS更新周期 | 20秒 |
| 责任人识别周期 | 6秒 |
| 离线缓存容量 | 500条记录 |
| 断网重连间隔 | 30秒 |
| 前端推送延迟 | <1秒（SSE） |
