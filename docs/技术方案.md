## 3. 数据流

```
传感器 → KF720温度采集 → STM32处理 → L610 MQTT上报
→ 华为云IoTDA → 规则转发 → 服务器:3000/api/iot/push
→ SQLite存储 + 报警检测 → SSE推送 → 浏览器实时更新
```

## 4. 嵌入式端设计

### 4.1 FreeRTOS双任务模型
- **KF720读卡任务**（2秒周期）：温度读取(0xC0) + 责任人盘存(0x22)交替调度
- **L610通信任务**：数据上报(HMPUB) + GPS查询(GTGIS) + 时间校准(CCLK)
- 配置：4KB栈、16KB堆、configTICK_RATE_HZ=1000

### 4.2 断网重连机制
```
HMPUB失败3次 → 判定断网 → CFUN复位 → 等8秒 → AT确认就绪
→ MIPCALL拨号 → HMCON连MQTT → 30秒重试周期
```

### 4.3 离线缓存结构
```c
typedef struct {
    int16_t temp_116_10;  // 温度×10
    int16_t temp_117_10;
    int16_t temp_118_10;
    uint8_t alarm;
    char gps[30];
    uint16_t time_offset_s;  // 相对base_time的偏移
} CacheRecord;
```

## 5. 服务端设计

### 5.1 多传感器自动适配
递归属性提取器遍历IoTDA推送JSON所有层级，自动将数值型属性识别为温度值。

### 5.2 动态数据存储
- 固定列：时间、联网状态等通用字段（SQL快速查询）
- JSON列：传感器ID→温度值映射（灵活扩展）
- 新增传感器无需修改表结构

### 5.3 双通道实时推送
- 主通道：SSE，<1秒延迟
- 降级通道：10秒HTTP轮询（SSE断开时自动切换）
- 重连：每5秒尝试重连SSE
